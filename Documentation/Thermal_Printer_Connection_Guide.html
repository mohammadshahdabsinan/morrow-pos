Posiflow KP307-UEWB | ESC/POS Protocol | Port 9100

Printer Model: Posiflow KP307-UEWB
Protocol: ESC/POS
Port: 9100 (default)
Connection: WiFi
Paper Size: 80mm (thermal receipt)
Status: ✅ Fully Tested & Working

Physical Printer Setup

1
Turn On Printer
  • Locate power button on printer (usually on side or back)
  • Press and hold for 2 seconds
  • Printer will beep and light turns blue
  • Wait 30 seconds for full startup
  • Blue WiFi indicator light should appear
2
Connect Printer to WiFi
  • Press and hold the MENU button (on top) for 3 seconds
  • Navigate with arrows (▲/▼) to: Network
  • Press ENTER
  • Select: WiFi Settings
  • Select your WiFi network name (SSID) from the list
  • Enter WiFi password using the control buttons
  • Press ENTER to connect
  • Wait for "Connected" message to appear
  • Press MENU to exit

Expected result: WiFi icon appears on printer display, blue light steady

3
Print Network Configuration Page
  • Press MENU on printer
  • Navigate to: Settings → System
  • Select: Print Network Config
  • Press ENTER
  • Printer will print a configuration page
⚠️ SAVE THE PRINTER IP ADDRESS FROM THIS PAGE!
Look for the line: IP Address: 192.168.x.x
Example: IP Address: 192.168.1.105
You will need this in the app!
4
Verify WiFi Connection (Optional)
  • Make sure your phone/tablet is on the SAME WiFi as printer ✓
  • Open a web browser on your phone
  • Type in address bar: http://192.168.1.105 (use your printer IP)
  • You should see the printer's web interface
  • If it loads = Connection successful ✓
  • If error = Check WiFi connection and IP address

Configure in Xtra Zone Billing App

5
Enter Printer IP in App
  • Open Xtra Zone Billing app on your phone/tablet
  • Tap: Business Settings tab
  • Scroll down to: 🖨️ Thermal Printer (WiFi) section
  • In the input field, enter your printer IP: 192.168.1.105
6
Test Printer Connection
  • Make sure printer and phone are on SAME WiFi ✓
  • Click: 📡 Test Connection button
  • Wait for response...

If green checkmark ✓: "Printer connected! Ready to print"

If red ✗: "Printer not found"

  • Check WiFi connection (both devices same network)
  • Verify printer IP is correct
  • Check printer is powered on
  • Try again
7
Save Printer IP
  • Once test is green ✓, click: ✓ Save Printer IP
  • You should see message: "Printer IP saved: 192.168.1.105"
  • Done! ✅

Troubleshooting

❌ "Printer not found" Error

  • ✓ Check both printer and phone are on SAME WiFi
  • ✓ Verify printer IP address is correct (check network config page)
  • ✓ Printer should be powered on with blue WiFi light
  • ✓ Try rebooting printer (turn off/on)
  • ✓ Move printer closer to WiFi router if signal weak

❌ Printer Connected but Won't Print

  • ✓ Check printer has paper (load paper if empty)
  • ✓ Test printer: press MENU → Self Test
  • ✓ Check printer firmware is up to date
  • ✓ Restart printer and try again

❌ Prints Garbage/Symbols Instead of Text

  • ✓ This means ESC/POS commands aren't supported
  • ✓ Check printer firmware version
  • ✓ Update firmware if available
  • ✓ Contact printer support with model number

❌ Can't Find Printer IP Address

  • ✓ Print network config page: MENU → Settings → Print Network Config
  • ✓ Look carefully for line starting with "IP Address:"
  • ✓ Write down the full address (e.g., 192.168.1.105)
  • ✓ Test by visiting it in browser: http://192.168.1.105
